### About Me

Master's student in **Cybersecurity** at the University of Minho, currently working on my dissertation on **Cybersecurity Debt**, a model for quantifying and governing accumulated security liabilities.

ISC2 Candidate, working toward the **Certified in Cybersecurity (CC)** certification as part of a broader GRC certification path (ISO 27001 Lead Auditor, CISA/CRISC, CISM).

In my free time, I'm building my own **homelab**, a rack based setup for self-hosting, home automation, media serving and network security.

I also keep my development skills active with small Python projects.
